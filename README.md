## 🚀 Featured Project

### Django AWS Deployment

Built and deployed a containerised Django application to AWS.

**Architecture:**

```text
GitHub
   ↓
GitHub Actions
   ↓ OIDC
AWS IAM
   ↓
Docker
   ↓
Amazon ECR
   ↓
ECS Fargate
   ↓
Django + Gunicorn
   ↓
RDS PostgreSQL
```

Key features:

- Dockerised Django application
- ECS Fargate deployment
- PostgreSQL database on Amazon RDS
- Database secrets stored in AWS Secrets Manager
- CloudWatch logging
- GitHub Actions CI/CD pipeline
- OIDC authentication between GitHub and AWS
- ECS rolling deployments
- `/health/` application health endpoint
- Real-world troubleshooting of Docker architecture and IAM/OIDC issues
